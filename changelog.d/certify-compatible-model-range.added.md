Source-enrichment certification can declare a publisher model compatibility range instead of the default exact pin: `--compatible-model-specifier 'policyengine-us>=2.0.1,<2.1'` with `--compatibility-claim-declared-by`. The range must name the built-with package, contain the version certification tested, and stop below the next major version; it is recorded in both the certified report and the release manifest with `basis: publisher_claim` and the declarer, and replayed at publish preflight. Core keeps its exact pin and a forged `core` claim is refused. Undeclared certification is unchanged.
